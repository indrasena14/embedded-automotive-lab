# Linux Basics (Track A)

Exercises and scripts from learning Linux on the PC (WSL2 Ubuntu 24.04).

| Folder | Topic | Weeks |
|---|---|---|
| `01-shell/` | Navigation, files, permissions, pipes, grep/find | 1–2 |
| `02-processes/` | Processes, signals, systemd | 3 |
| `03-scripting/` | Bash scripts, Makefiles | 4 |
| `04-networking/` | ip, ss, tcpdump, ssh, `/proc`, `/sys` | 5 |
| `05-sysprog/` | C system programming: files, fork/exec, threads, sockets | 6–12 |

Create each folder when you start that topic.
